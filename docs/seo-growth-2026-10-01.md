# 2026-10-01 首轮站内 SEO

## 范围

本轮只做站内 SEO，不做站外推广。以下记录 2026-10-01 的实现与本地验收；这些改动在 2026-10-09 按用户“全部发布”的要求纳入中英文版本一起发布。

- 优化 `/compress-image-to-200kb`、`/compress-png`、`/webp-to-jpg` 的标题、描述或使用说明。
- 新增三篇围绕上传限制、透明 PNG、WebP 兼容性的教程，每篇附公开样例、操作步骤、实测截图和失败排查。
- 首页、指南列表、工具页与教程互相链接；三篇文章生成独立静态 HTML、canonical 和结构化数据。
- sitemap 纳入新页面，并按实际改动更新相关页面日期。

## 验证

- `npm run lint`、`npm run build`、`npm run seo:check`、`git diff --check` 均通过。
- 19 个静态 HTML 的本地链接和资源目标检查通过；路由按生成的 `.html` 文件解析。
- 本地构建预览检查三篇文章在 390px 手机宽度的排版，无横向溢出；200KB 教程到工具的跳转正常。
- 本地 Chromium 中实际处理项目样例，得到教程截图：PNG 原图在 200KB/JPG 设置下输出 147.29KB、1140×712；PNG 默认 82% 输出 462.53KB、1200×750；WebP 默认 88% 转 JPG 得到 80.42KB。以上仅是这些样例的 UI 结果，不代表所有图片的表现或已保存下载文件的验证。
- 示例 PNG 为不透明风景图，不能作为透明通道效果的测试证据；教程明确了这一点。本轮未修改图像处理算法。

## 上线与效果观察

1. 沿用现有 Cloudflare Pages 发布流程和生产环境变量，保留既有匿名工具事件统计及 Analytics Engine 绑定；不要直接将未配置生产统计变量的本地预览构建当作发布产物。
2. 发布后检查三个新 URL 的 HTTP 状态、静态正文、canonical、图片和线上 sitemap。部署成功与搜索引擎收录是不同状态。
3. 在已验证的站长后台查看或提交 sitemap，记录新 URL 的收录状态；没有后台证据时不宣称已收录。
4. 以相同时间窗口比较自然搜索访问、教程入口、工具页入口和工具事件。首次观察可设在上线后 2–4 周；这只是评估计划，本轮未创建自动监控。
5. 有展示但点击低时再调整标题和摘要；有访问但操作少时检查教程到工具的路径。样本不足时继续积累，不将短期波动当作增长结论。
